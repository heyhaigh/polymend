Error states

Every way a file can be refused, with the exact words the tool shows. The messages below are produced by the real code, not copied, so this page cannot drift from the tool. To see one on the tool itself, drop that kind of file on it.

The upload card while a file is held over the page

The edge brightens and the dots fill the card. Both fade in and out over 0.3 seconds.

Drop a model here

A .glb or .stl file. Anywhere on this page works.

That file cannot be used

Polymend takes .glb and .stl files.

A file that is clearly not a model, such as a picture or a PDF, cross-fades the card to pink, hides the button, and gives it a small repeating shake while it is held there. Browsers reveal a file's type but not its name before the drop, and Safari reveals neither, so some wrong files are only caught once dropped.

When a file cannot be used

Each appears as a pink outcome card at the top of the page, in place of the title and description, with the low bell chime. The status badge beside "Runs in your browser for free" reads "Not repaired".
